# Постобработка OCR паспорта РФ

Решение тестового задания (см. `TASK.md`): по выводу OCR-модели для каждого
документа принимается решение «принять» (с выдачей 10 полей) или «отклонить».
Цель — максимум принятых при нулевом принятии документов с ошибками; отдельным
жёстким правилом отсекаются паспорта, недействительные на 01.10.2026.

## Запуск

```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Только CPU, без сети, только стандартная библиотека Python. Детерминировано.
Третий (необязательный) аргумент — путь для подробного лога решений
(используется калибровкой): `python postprocess.py in.jsonl out.jsonl log.jsonl`.

## Репозиторий

| Путь | Назначение |
|---|---|
| `postprocess.py` | точка входа (CLI) |
| `pp/parse.py` | разбор viz-зоны, нормализация, посимвольные conf |
| `pp/mrz.py` | разбор МНР 2×44, контрольные цифры ИКАО 7-3-1 (поз. 9/19/42/43), поз. 28 = 10-я цифра серии |
| `pp/translit.py` | эмпирическая таблица транслитерации (Й→Q, Ч→3, Ш→4, Ю→7, Я→8…) |
| `pp/engine.py` | верификация/коррекция полей и решающее правило |
| `pp/orgs.py` | пул названий подразделений (CSV ∪ разметка train), leave-one-out |
| `pp/place.py` | структурные проверки места рождения (маркеры, админ-токены, словарные аномалии) |
| `pp/validity.py` | правило 14/20/45 лет против 01.10.2026 |
| `pp/constants.py` | все пороги с обоснованиями в комментариях |
| `scripts/` | derive_translit / parse_check / mrz_agreement / selfcheck / calibrate |
| `analysis_out/` | артефакты анализа (таблица транслитерации, калибровка) |
| `plan/stages.md` | план работ, гейты, журнал поправок |
| `REPORT.md` | отчёт (≤2 стр.) с обязательным прогнозом |

## Самопроверка

```bash
python evaluate.py <answers.jsonl> data/train_labels.jsonl   # точность полей
python scripts/selfcheck.py <answers.jsonl>                  # + действительность
python scripts/calibrate.py                                  # 5-фолдовая стабильность
```

Результаты и прогноз для test — в `REPORT.md`; журнал решений и гейты — в
`plan/stages.md`.
